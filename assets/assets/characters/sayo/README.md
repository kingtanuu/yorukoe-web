# 立ち絵の差し替え方

このフォルダに以下のファイル名で PNG を置くと、そのまま画面に反映されます。
置いていない表情は、コードで描いた簡易絵にフォールバックします。

- normal.png     ふつう
- smile.png      笑顔
- shy.png        照れ
- sad.png        落ち込み
- worried.png    心配
- surprised.png  驚き
- sleepy.png     眠い
- serious.png    真剣
- angry.png      むくれ・怒り

推奨: 背景透過 PNG / 縦 1400px 以上 / 胸から上のバストアップ / 顔の中心が横位置の中央
